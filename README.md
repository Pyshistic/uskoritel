# Ускоритель — очистка и ускорение для Android

Kotlin + Jetpack Compose, Android 8.0 и новее. Тёмный интерфейс, 4 вкладки:

| Вкладка | Что делает |
|---|---|
| **Ускорение** | ОЗУ, хранилище и батарея в реальном времени. Кнопка «Ускорить» останавливает фоновые процессы других приложений (до Android 13 включительно) и чистит свой кэш |
| **Очистка** | Ищет мусор: старые APK, .tmp/.log, кэш миниатюр, пустые папки, большие файлы. Перед удалением всё видно и можно снять галочки |
| **Батарея** | Заряд, состояние, температура, напряжение, ток + советы и быстрые переходы в настройки энергосбережения |
| **Приложения** | Топ приложений по активности за 24 часа, кнопка «остановить» и переход в настройки приложения (там «Очистить кэш») |

## Как получить APK

### Вариант 1 — без установки программ (через GitHub)
1. Создай репозиторий на github.com и загрузи туда все файлы из этой папки (включая скрытую папку `.github`).
2. Открой вкладку **Actions** — сборка запустится сама (около 5 минут).
3. Когда появится зелёная галочка, открой сборку и скачай архив **Uskoritel-apk** внизу страницы.
4. Перекинь APK на телефон и установи (телефон попросит разрешить установку из неизвестных источников).

### Вариант 2 — Android Studio
1. Установи Android Studio, нажми **Open** и выбери папку `Uskoritel`.
2. Дождись синхронизации Gradle.
3. Подключи телефон по USB (с включённой отладкой) и нажми ▶ Run.
   Или **Build → Build APK(s)** — файл появится в `app/build/outputs/apk/`.

## Разрешения
- **Доступ ко всем файлам** — для поиска мусора. Ничего не удаляется без подтверждения.
- **Доступ к истории использования** — чтобы показать самые активные приложения.

## Честно о «ускорении»
Android сам управляет оперативной памятью: свободная ОЗУ — не всегда хорошо, а закрытые
приложения часто перезапускаются и тратят ещё больше заряда. С Android 14 система вообще
не разрешает приложениям закрывать чужие процессы. Поэтому реальную пользу дают очистка
памяти, отключение прожорливых фоновых приложений и настройки батареи — на этом
приложение и сделано.
